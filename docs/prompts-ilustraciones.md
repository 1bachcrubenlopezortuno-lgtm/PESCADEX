# Prompts para las ilustraciones de la Pescadex

Estilo **A · lámina de guía de campo (acuarela)**. Un prompt por especie, ya relleno.

## Reglas para que todas queden iguales

- Usa **siempre el mismo generador y el mismo prompt base**; solo cambia el pez.
- **Cuadradas (1:1)**, mínimo 512×512, **fondo transparente** (PNG). Si el generador no da transparencia, pide fondo blanco liso y quítalo después (Canva: *Quitar fondo*).
- El pez **mirando a la izquierda**, de perfil, entero y centrado.
- Guarda cada imagen con el **id** de la especie: `dorada.png`, `urta.png`… (columna *Archivo*).
- Los cefalópodos (pulpo, choco, calamar) no son peces: el prompt ya lo tiene en cuenta.

## Prompt base

```
Scientific field-guide watercolor illustration of a {NOMBRE CIENTÍFICO} ({NOMBRE COMÚN}), a single adult fish shown in full side profile facing left, entire body visible including all fins and tail, anatomically accurate shape, fin rays, scale pattern and true natural colors, delicate fine ink outlines with soft layered watercolor washes and subtle paper-grain texture, soft even lighting, isolated on a plain transparent background, centered with generous margin, no water, no rocks, no plants, no shadow on the ground, no text, no labels, no border, no frame, square 1:1 composition, consistent vintage natural-history plate style
```
